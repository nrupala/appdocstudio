# AppDocStudio browser extension — PARKED

Status (owner's ruling, 2026-11-09): **not released, in any form.**
Development resumes at a later date.

Why: Chrome extensions from this house are released only through the
Chrome Web Store, under Google's policies — never self-hosted, never
sideloaded, never through any channel that bypasses Google's review.
Our developer account's publishing-limit increase is under review with
Google (we are a new company), so this extension waits its turn.

The source here (a Manifest V3 popup paired with the local
`appdocstudio serve` API) is kept as the starting point for that later
development. Nothing here is a distribution: there is no packaged
download, and loading the source locally is for our own development
only.

When the store door opens, the release checklist is: store listing,
privacy declaration (the extension talks only to the local API on
loopback; no analytics, no tracking), and the house release gate.

Note: a packaged self-hosted zip was briefly added on 2026-11-09 on a
misreading of the owner's words and was removed the same evening when
he clarified the rule. It was never a release channel.
